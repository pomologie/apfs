# apfs technology and dependencies

Rust edition 2024/resolver 3, pinned toolchain and tested MSRV; mandatory `no_std + alloc` for core/format/container/reader/writer (core-only codecs where natural); std permitted in bulk builder, host adapters and hosted concurrency. EES-1 §3a defines target/feature gates. Explicit little-endian codecs from bounded byte slices; object checksum primitive implemented and tested against published algorithm and native fixtures (not CRC32). Generic compression primitives via vetted libraries: zlib (`flate2` plus pure Rust backend), LZVN/LZFSE via qualified pure Rust candidate, additional decmpfs framing and types only after evidence. No assumption one decoder supports every APFS compression type. Crypto later uses vetted implementations for actual qualified format algorithms/key wrapping/KDF, zeroize and secret-bearing opaque types; no custom cryptographic primitives or unauthorized key recovery. `serde` optional reports, `clap`, `indicatif` CLI, `proptest`, cargo-fuzz, controlled benchmarks, cargo-deny and audit. Do not copy implementation code from APSL/GPL/proprietary sources without authorized policy; source ledger and independent evidence mandatory. `fstool`, `ferrosys`, `apfs`, `libfsapfs`, `apfs-fuse`, `linux-apfs-rw` are candidate differential references with license and capability review, never runtime engine dependencies. Apple's 2020 reference S12 is starting evidence, not sufficient for every Sequoia-era feature. Advanced writable, encryption and boot-related milestones require review of applicable patents and licenses. No Apple tools required for ordinary reader or fresh builder execution; Apple tools only oracle or explicit external test adapter. No mandatory HFS+ or dmgez linkage.

## Verification integration

The local `VERIFICATION.md` and `verification/obligations.json` define mandatory profile-specific verification gates in addition to the original acceptance tests. Apply ecosystem standard EVS-1 (copy `shared/VERIFICATION.md` as `docs/architecture/ECOSYSTEM_VERIFICATION.md`). No required proof, model check, native test or critical fault gate can be substituted by coverage or a self-generated round trip. `cargo-nextest`, property tests, fuzz/corpus replay, coverage and deterministic architecture checks are required; formal methods activate at the milestones in the obligation registry.
